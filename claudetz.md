Нужно разработать полноценный фронтенд-проект для приложения под названием FinFuture умного финансового ассистента для зумеров, который помогает управлять личными финансами, а не просто фиксировать траты.

Цель проекта:
Создать работающий frontend и демонстрационный интерфейс сервиса, который:
* отображает финансовое состояние пользователя;
* позволяет добавлять и анализировать транзакции;
* показывает главный дашборд с балансом и ключевыми метриками;
* визуализирует поведение пользователя;
* использует «умную» логику для прогнозирования, когда у пользователя могут закончиться деньги, на основе его расходов;
* включает элементы ИИ и геймификации.

Основная идея продукта:
«Личный финансовый ИИ-ассистент для зумеров: от хаоса в тратах к осознанному капиталу».

Функциональные требования:
1. Главный дашборд
* текущий баланс;
* доходы и расходы;
* график трат по дням/неделям/месяцам;
* карточки с аналитикой;
* прогноз, когда могут закончиться деньги при текущем темпе расходов;
* блок с финансовыми советами от ассистента.
* Диаграммы

Экран добавления транзакции
- сумма;
- категория;
- дата;
- тип операции: доход / расход;
- комментарий;
- кнопка сохранения;
- валидация формы.

Категории и транзакции
- список транзакций;
- фильтрация по категориям;
- сортировка по дате и сумме;
- понятный и современный UI.

ИИ
- добавляем чат-бота который будет помогать со всем 
- финансовый советник который будет помогать тратить деньги и не просирать в пустую

 Геймификация
- система достижений / badges;
- примеры: «7 дней без импульсивных покупок», «Первый сохранённый бюджет», «Мастер экономии»;
- визуальный блок прогресса пользователя.

Архитектура - Нужно спроектировать структуру данных и логическую архитектуру:
- пользователи;
- транзакции;
- категории;
- достижения;
- аналитика;
- прогноз расходов.
